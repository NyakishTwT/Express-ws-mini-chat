# Express WebSockets Mini Chat

Fullstack-приложение для обмена сообщениями в реальном времени с чистой слоистой архитектурой, валидацией данных и JWT-авторизацией

## Архитектурные решения и фичи

Проект написан на ES-модулях (`"type": "module"`) и спроектирован с чётким разделением ответственности (Separation of Concerns):

* **Чистые WebSockets (библиотека `ws`):** Сознательный отказ от тяжелых фреймворков вроде Socket.io. Весь реалтайм-менеджмент и управление соединениями вынесены в изолированный модуль `wsHub.js`. Это снижает оверхед и дает полный контроль над протоколом
* **Слоистая архитектура** Логика приложения отделена от HTTP-слоя. Маршруты (`routes`) вызывают контроллеры (`controllers`), которые отвечают только за прием/отправку запросов, а вся работа с базой данных и бизнес-логика инкапсулирована в сервисах (`services`)
* **Строгая валидация с Joi:** Все входящие данные (регистрация, логин, отправка сообщений) проходят жесткую проверку на уровне middleware до того, как попадут в контроллеры
* **Безопасность** Реализована полноценная авторизация на сессионных токенах JWT, кастомный middleware `protect.js` для защиты эндпоинтов и хэширование паролей с помощью bcrypt
* **Централизованная обработка ошибок** Использование кастомных middleware для обработки несуществующих роутов (`404 Not Found`) и глобального перехвата исключений (`errorHandler.js`), что гарантирует стабильность сервера при падениях
* **Готовность к тестированию** Точка входа разделена на конфигурацию экспресс-приложения (`app.js`) и непосредственный запуск сервера (`server.js`). Это позволяет изолированно тестировать API без поднятия сетевых интерфейсов

##  Стек технологий

* **Backend:** Node.js, Express 5
* **Протокол реалтайма:** Нативные WebSockets (пакет `ws`)
* **База данных:** SQLite (библиотека `sqlite3`)
* **Валидация и безопасность:** Joi, JSON Web Tokens, bcrypt
* **Инструменты разработки:** Nodemon, Dotenv, CORS

##  Обзор структуры проекта

* `db/db.js` — Инициализация SQLite и управление схемой данных
* `public/` — Статическая фронтенд-часть приложения (клиентский скрипт, стили и интерфейс)
* `src/config/` — Конфигурационные файлы проекта (параметры JWT).
* `src/middleware/` — Защита роутов, валидация и централизованный сборщик ошибок.
* `src/routes/` & `src/controllers/` — Изолированная обработка HTTP-запросов.
* `src/services/` — Слой бизнес-логики для работы с историей чатов и пользователями.
* `src/wsHub.js` — Логика вещания (broadcasting) сокет-сообщений подключенным клиентам.

## Локальный запуск

1. Склонируйте репозиторий и перейдите в папку проекта.

2. Установите зависимости:
```bash
npm install
```

3. Создайте файл `.env` в корне проекта и укажите параметры:
```env
PORT=3000
JWT_SECRET=your_super_secret_key
```

4. Запустите сервер в удобном для вас режиме:

**Режим разработки** (автоматический перезапуск при изменении кода):
```bash
npm run dev
```

**Обычный запуск** (стандартный старт без отслеживания изменений):
```bash
npm start
```

5. Откройте приложение в браузере:
```text
http://localhost:3000
```
